# AI 讲稿测试版使用说明

修改版入口：http://127.0.0.1:4173/ 。原版对照仍为 http://127.0.0.1:4174/ 。

1. 打开项目，进入「分镜视频」，在右侧点击「AI 按页生成讲解稿」。
2. 填写兼容 Chat Completions 的 API 地址、模型名称和 API Key。默认地址为 `https://api.deepseek.com`，默认模型为 `deepseek-chat`。密钥仅存在当前面板内存，关闭面板后需重新输入，不写入课件或浏览器保存记录。
3. 建议先选「当前页」，设置教学对象、讲解程度；图形含义和无法提取的公式可写入补充说明。全部页模式会把这段说明用于每一页。
4. 点击「生成讲解草稿」。检查节点内容及来源，必要时修改，再点击「应用本页可更新节点」。只生成草稿不会改原讲稿。
5. 回到时间轴拖动旁白并绑定动画锚点，或在右侧设置现有动画绑定；随后生成试听、生成视频。

实现方式：本地读取文字、表格、部分内嵌 DOCX，去除常见模板导航，按页面和原动画顺序整理内容 ID。每页一次模型请求，默认串行；带少量相邻页上下文，不发送整份 PPT、图片或历史对话。相同材料与配置复用当前分镜工作台内存缓存；「重新生成本页」强制重新请求。每页输入上限为 14000 字符，超限会提示精简，不会静默截掉本页正文。

手工修改的讲稿默认保护；在草稿面板中修订后应用也自动保护。需要再次覆盖时，先在右侧取消「保护当前讲稿」。应用前还会检查原稿是否已变化。应用会更新旁白和字幕，并清除对应旧试听音频，保留动画绑定。关闭面板会取消当前请求，并丢弃未应用的草稿编辑；已应用内容按原有机制保存到本机项目。

也可在启动服务前设置 `DEEPSEEK_API_KEY`，或 `STORYBOARD_AI_API_KEY`、`STORYBOARD_AI_BASE_URL`、`STORYBOARD_AI_MODEL`，然后在面板使用服务端配置。客户端指定的地址不会继承服务端密钥。

首版边界：节点沿用现有分镜，可留空旁白；暂不支持任意拆分/合并讲稿节点、逐词对齐。没有 OCR 或多模态识图。图片、旧版公式及复杂 Word 公式会提示提取缺口；建议先补充信息或手工修订。大页面目前提示拆分，不自动分块。模型输出必须包含合法节点 ID 和来源，不合格结果报错，不用模板冒充 AI。模型对来源的正确解释仍需人工检查。

验证：材料/协议、Word 提取、API 适配器、草稿保护、串行队列、取消与缓存测试，以及原有动画绑定回归测试；浏览器通过本地模拟接口验证草稿编辑、应用、保护和刷新恢复。没有配置真实模型密钥，因此不把模拟样稿当作 DeepSeek 生成质量或耗时结论。

## 输出截断修复

首轮输出预算按讲解程度与节点结构计算，为 4096～6144 tokens；整页讲稿建议字数为简明 300、一般 600、详细 1000。若模型明确返回长度截断且结果未通过完整性校验，只重试当前页一次，将输出预算提高到 8192，仍是串行请求、不追加历史输出。此重试可能增加该页耗时和模型费用。若返回值已经是合法完整草稿，即使服务商标注 length 也可使用。总请求时间上限 180 秒，关闭或取消仍会中断请求。

## 应用讲稿卡顿优化（2026-09-22）

应用本页改为一次更新分镜状态、一次更新时间轴，在批量修改完成后统一重算整份课件，避免每个节点重复全局重算。长时间轴刻度最多约 1000 个，降低长讲稿导致的 DOM 数量增长；拖拽的时间精度不变。应用期间提供处理中状态并禁止重复点击草稿应用按钮。

验证：32 个分镜相关测试文件、346 项测试通过，包含批量提交次数、跨分镜动画绑定、字幕/讲稿更新及刻度上限；React 类型检查、演示应用构建通过。合成基准为 240 分镜、40 个节点一次应用，时间轴运算由约 200 毫秒降至约 6 毫秒。此数字不包含真实浏览器渲染耗时，不能等同于整页交互耗时。

## 来源校验、整批应用与旧时间轴恢复（2026-09-22）

- 对模型返回的结构/来源校验失败自动纠正一次，不编造来源 ID。与截断重试共用总计两次请求的上限。
- 增加「一键应用所有已生成页」：单次批量提交，跳过已应用页、受保护节点和原稿已变化节点。
- 为原来没有讲稿的分镜补建旁白和字幕片段，重新打开旧项目也会补齐；节点选择或时长变化后，将选中分镜滚动回可见范围。
- 视频导出前验证关键时序，并显示后端原始错误码和解释。服务端日志只记录拒绝代码，不记录讲稿、密钥。
- 旧项目出现非有限、非数字、负数或超出单镜导出范围的时序时，先将完整原快照备份到本机 localStorage 的 `pptx-viewer:storyboard-timing-backup:<项目ID>`，再按原动画及现有讲稿重建。讲稿及保护字段不改，保留可解析绑定；手动绝对位置回到默认。备份失败时不自动改写。修复触发需重新进入分镜工作台。

验证：分镜测试全集 34 文件、352 项通过；新增旧快照备份测试单独通过；模型适配器 6 项通过；FFmpeg 视频/音频/字幕集成测试 2 项通过；类型检查与构建通过。浏览器样例 7 页一键应用成功，任务 4038787a-8856-453c-a324-b7e6f103f1e1 已完成。真实课件原始解析、模拟整批讲稿应用和重复恢复未复现超长首镜，因此旧项目异常时序的最初触发条件仍待进一步样本确认；未宣称已定位所有根因。
