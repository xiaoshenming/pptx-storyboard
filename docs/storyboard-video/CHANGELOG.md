## 0.1.0 - 2026-09-10

首个经过完整 PPTX 实测的工程化版本。

### 新增

- 中文分镜视频工作台、讲稿编辑区和多轨时间轴；
- PowerPoint 原生动画点击组编译，支持同起与顺序动画；
- 低内存关键状态捕获和 1080p 视频输出；
- Edge 晓晓神经语音与腾讯云 TTS 适配器；
- 任务 ID、子任务进度、取消、恢复和产物回执；
- 4 路 TTS、8 路 NVENC 分片并行；
- SRT 字幕、事件级音画锚定和完整媒体验收。

### 修复

- 去除“这一页主要讲解”等泛化重复话术；
- 只讲当前动画组新增内容，退出和无文本动画保持静音；
- 修复题号、零的数量、残缺算式和课堂小结语序；
- 保留字幕标点并保证字幕时间不重叠；
- Edge TTS 瞬时无音频返回时自动有界重试。
- 覆盖“整十、整百 0 前面”和“整十数、整百数 0 前面”两种口语化输入。

### 验证基线

- 输入：`1.口算乘法.pptx`，19 页；
- 解析结果：127 个画面状态，其中 108 个动画点击组；
- 自动讲稿：83 段；
- 回归测试：100 项通过；
- 质量门槛：H.264/AAC、1920×1080、30fps、完整解码、音画锚点一致、SRT
  单调无重叠。

### 已知边界

- 当前是动画关键状态之间的平滑视频，不保证逐帧复刻所有复杂运动路径；
- 当前主要性能瓶颈是浏览器端 DOM 到 PNG 的关键状态捕获；
- 腾讯云正式切换仍需要专用最小权限 CAM TTS 密钥；
- DeepSeek 自动润色依赖用户配置 API Key，默认确定性讲稿不依赖外部 LLM。
