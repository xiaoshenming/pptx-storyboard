# PPT 分镜视频变更日志

## 0.2.0 - 2026-09-11

### 新增

- 旁白与原生动画的显式绑定：TimelineBinding 模型（动画前/同时/动画后
  三种模式 + 偏移 + 锁定），绑定是时间事实源、startMs 为派生值；
- 时间轴"点击即绑定"：点动画卡或菱形锚点立即绑定，再点解除；
  8px 磁吸、自由落点解绑、亚阈值抖动保护、pointercancel 回弹；
- 绑定编辑器：跟随动画下拉（本分镜/其他分镜分组）、后果预览
  （"当前 X.Xs → 绑定后 Y.Ys"）、建议行可点击（同分镜首个有文本的
  进入动画）、语义说明文案；
- 动画卡可读化：锚点编号 + 预设类型 + 目标元素（形状/图片等中文
  类型标签）+ 触发方式，同起动画绘制括号组头；
- 真实播放头：绝对时间播放引擎、键盘逐帧步进、时间尺拖拽定位、
  预览真实进度条；
- 导出绑定回执：manifest 记录每段旁白的 binding、resolvedStartMs
  与 bindingRevision（协议保持 version 1，服务端无感）；
- 技术交接文档 `HANDOVER.zh-CN.md`（重点：原生动画时间戳捕捉全链路）。

### 优化

- 静音节奏分级压缩：无配音动画分镜按退出/揭示类压缩时长底薪；
  实测《口算乘法》静音总时长 104s 降至 75s、最长无讲解段 11.8s
  降至 8.4s、全片 7:19 缩至 6:56。

### 验证

- 回归基线：react 包 419 文件 7073 测试全部通过；
- 端到端：《口算乘法》19 页 127 分镜成片，NVENC 流水线 91.4s，
  SHA 与回执一致、完整解码零错误、SRT 零重叠、绑定回执零漂移；
- 绑定交互经三轮多智能体交叉评审，三领域终审 96/95/96 分。

## 0.1.0 - 2026-09-10

首个经过完整 PPTX 实测的工程化版本。

### 新增

- 中文分镜视频工作台、讲稿编辑区和多轨时间轴；
- PowerPoint 原生动画点击组编译，支持同起与顺序动画；
- 低内存关键状态捕获和 1080p 视频输出；
- Edge 晓晓神经语音与腾讯云 TTS 适配器；
- 任务 ID、子任务进度、取消、恢复和产物回执；
- 4 路 TTS、8 路 NVENC 分片并行；
- SRT 字幕、事件级音画锚定和完整媒体验收。

### 修复

- 去除“这一页主要讲解”等泛化重复话术；
- 只讲当前动画组新增内容，退出和无文本动画保持静音；
- 修复题号、零的数量、残缺算式和课堂小结语序；
- 保留字幕标点并保证字幕时间不重叠；
- Edge TTS 瞬时无音频返回时自动有界重试。
- 覆盖“整十、整百 0 前面”和“整十数、整百数 0 前面”两种口语化输入。

### 验证基线

- 输入：`1.口算乘法.pptx`，19 页；
- 解析结果：127 个画面状态，其中 108 个动画点击组；
- 自动讲稿：83 段；
- 回归测试：100 项通过；
- 质量门槛：H.264/AAC、1920×1080、30fps、完整解码、音画锚点一致、SRT
  单调无重叠。

### 已知边界

- 当前是动画关键状态之间的平滑视频，不保证逐帧复刻所有复杂运动路径；
- 当前主要性能瓶颈是浏览器端 DOM 到 PNG 的关键状态捕获；
- 腾讯云正式切换仍需要专用最小权限 CAM TTS 密钥；
- DeepSeek 自动润色依赖用户配置 API Key，默认确定性讲稿不依赖外部 LLM。
