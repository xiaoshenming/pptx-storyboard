## 验证中发现并固化的回归

零覆盖成片暴露了“整十数、整百数 0 前面”这一文本变体未被原规则完整口语化，
会让神经语音在“零”两侧产生不自然停顿。发布版本已把带“数”和不带“数”的
两种写法纳入同一规则及参数化测试。该修复发生在本回执所列成片之后，因此此成片
用于证明零覆盖自动链路，不作为最终教学语言质量样片。

最终教学语言质量样片仍为：

- `/home/ming/下载/1.口算乘法-完美动画配音视频.mp4`
- SHA-256：`5692a2b3fec5098a585f38ca9a637f96db1b3efe77b4a49b246dc50d7d6c83b2`

该样片的视觉、动画分组、TTS、时间轴和混流均由服务完成；其中 4 条讲稿在 QA
阶段做过定向重混。发布代码已将这些问题转化为通用规则。
